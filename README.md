#NUST Hospital Patient Management System

A command-line application built in Python that allows hospital staff to manage patient records securely using an SQLite database.

## Features
*   **Create:** Add new patients with their name, age, and illness.
*   **Read:** View a list of all registered patients.
*   **Search:** Find specific patients using a partial name match (SQL `LIKE`).
*   **Delete:** Remove patient records safely using their unique ID.

## Technologies Used
*   **Python:** Core programming language and logic.
*   **SQLite:** Lightweight relational database for data storage.
*   **Git & GitHub:** Version control and portfolio hosting.

## Skills Demonstrated
*   CRUD (Create, Read, Update, Delete) database operations.
*   Error handling using `try...except` blocks (preventing crashes on invalid inputs).
*   SQL Injection prevention using parameterized queries (`?` placeholders).
*   Modular code using functions.

## How to Run
1. Clone this repository.
2. Ensure you have Python installed.
3. Run `python main_app.py` in your terminal.
4. Follow the on-screen menu to manage patients.
